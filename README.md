# ローマ字タイピングバトル

ローマ字を見て、打って、覚える。小学生向けのタイピング学習ゲームです。NAVI Fantasyの仲間とバトルしながら、ひらがなとローマ字の対応や、言葉・文章の入力に慣れていきます。

**公開ページ：** https://tt-sensei.github.io/typing/

## 遊び方

1. バトルモードを選びます。
2. 主人公を選びます。
3. 出題範囲やローマ字表示をカードから選びます。
4. 「START!」を押し、キーボードで入力します。

正しい入力が完成すると攻撃します。Enterキーを押す必要はありません。入力を間違えても、正しい入力を続けて完成を目指します。敵が攻撃ラインに到達するとHPが減り、コンボがリセットされます。

## 4つのバトルモード

- **かなバトル（60秒）**：ひらがな1文字を入力します。母音から始め、行ごとや濁音・半濁音、小さい「ゃ・ゅ・ょ」など、範囲を選んで練習できます。
- **ことばバトル（60秒）**：短い言葉を入力します。「やさしい」「ふつう」「むずかしい」「ぜんぶ」から出題範囲を選べます。
- **マスターバトル（60秒）**：ローマ字を見ずに入力するチャレンジです。入力の進み具合に応じてヒントが表示されます。
- **グランドマスター（120秒）**：回文、ダジャレ、早口言葉などの文章に挑戦します。「ローマ字あり」「ローマ字なし」をカードで切り替えられます。

## 苦手ローマ字特訓

スタート画面から、時間制限のない特訓を始められます。プレイ履歴や復習データをもとに苦手な問題を優先し、初めての問題はローマ字を表示、2回目以降は思い出して入力する練習に切り替わります。3回間違えると答えが表示され、いつでも特訓を終了できます。

## スコアとコレクション

- 正しい入力やコンボに応じてスコアを獲得します。
- モード別のベストスコアなどを記録します。
- バトルや学習の積み重ねでバッジを集められます。
- 効果音はゲーム内でON/OFFを切り替えられます。

## ローマ字の考え方

画面に表示するローマ字は、文化庁の「ローマ字のつづり方」（2025年12月22日 内閣告示第4号）の本表を基準にしています。PC入力で広く使われる別のつづりも、対応するものは入力できます。

例：画面表示は `shi / chi / tsu / fu / ji / sha / cha`。入力時は `si / ti / tu / hu / zi / sya / tya` なども受け付けます。

表示用のつづりと入力判定用の候補は `src/data.js` に分けて定義しています。促音・拗音などの入力処理は `src/romaji.js` で扱います。

参考資料：文化庁「ローマ字のつづり方」
https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/roma/index2.html

## データの保存と技術構成

HTML・CSS・JavaScriptで動作し、GitHub Pagesで公開できる構成です。ゲームサーバー、データベース、APIキーは必要ありません。

- **学習記録・設定：** ブラウザーの `localStorage` に保存します。同じブラウザー内で利用するための保存であり、別の端末やブラウザーとは自動で同期されません。ブラウザーデータを消去すると記録も消えることがあります。
- **効果音：** Web Audio APIで生成します。
- **キャラクター・背景・バッジ画像：** 公開されているTT-sensei関連の素材を読み込んで表示します。プレイ時にはインターネット接続が必要です。

主なファイル：

```text
index.html
styles.css
src/
  app.js             画面表示・ゲーム進行
  data.js            ローマ字・出題範囲・ことば・キャラクター・バッジ
  sentence-data.js   グランドマスターの文章データ
  monster-data.js    モンスターと出現グループ
  romaji.js          ローマ字の表示・入力判定
  storage.js         学習記録・復習キュー・保存処理
  audio.js           効果音
```
