# ローマ字タイピングバトル

ローマ字を見て、打って、覚える。小学生向けのタイピング学習ゲームです。NAVI Fantasyの仲間と一緒に、キーの位置からひらがな・ことば・文章の入力まで、少しずつ練習できます。

**公開ページ：** https://tt-sensei.github.io/typing/

## まずは基本の練習から

タイピングが初めての人は、ホームポジションの練習から始められます。

**[ホームポジションの練習を始める](https://tt-sensei.github.io/typing/beginner/)**

1. F と J の小さな突起を見つけ、人差し指を置く
2. ほかの指を A・S・D と K・L・; に置く
3. ホームポジションのキーを順番に押す
4. 小指・薬指・中指・人差し指の動かし方を練習する
5. 母音 A・I・U・E・O を練習する

画面の案内に沿って進めます。最初のホームポジション確認では、スペースキーを押して次へ進みます。

## 遊び方

1. スタート画面で遊ぶモードを選びます。
2. 主人公を選びます。
3. 出題範囲やローマ字表示など、必要な設定を選びます。
4. 「START!」を押し、キーボードで入力します。

正しい入力が完成すると攻撃します。Enter キーを押す必要はありません。入力を間違えても、正しい入力を続けて完成を目指します。敵が攻撃ラインに到達すると HP が減り、コンボがリセットされます。

## バトルモード

- **かなバトル（60秒）**：ひらがな1文字を入力します。母音、行ごとのかな、濁音・半濁音、小さい「ゃ・ゅ・ょ」など、出題範囲を選べます。
- **ことばバトル（60秒）**：短いことばを入力します。「やさしい」「ふつう」「むずかしい」「ぜんぶ」から出題範囲を選べます。
- **マスターバトル（60秒）**：ローマ字を見ずに入力するチャレンジです。入力の進み具合に応じてヒントが表示されます。
- **グランドマスター（120秒）**：回文、ダジャレ、早口言葉などの文章に挑戦します。ローマ字表示の有無を切り替えられます。

## 苦手特訓

スタート画面の「苦手特訓」では、時間制限なしで復習できます。プレイ履歴や復習データをもとに苦手な問題を優先し、初めての問題はローマ字を表示、2回目以降は思い出して入力する練習に切り替わります。3回間違えると答えが表示されます。苦手な問題を繰り返し練習し、できるようになったらバトルに再挑戦できます。

## スコア・バッジ・効果音

- 正しい入力やコンボに応じてスコアを獲得します。
- モード別のベストスコアなどを記録します。
- バトルや学習の積み重ねでバッジを集められます。
- 効果音はゲーム内で ON／OFF を切り替えられます。

## ローマ字の考え方

画面に表示するローマ字は、文化庁の「ローマ字のつづり方」（2025年12月22日 内閣告示第4号）の本表を基準にしています。対応する範囲で、PC入力で広く使われる別のつづりも受け付けます。

例：画面表示は `shi`・`chi`・`tsu`・`fu`・`ji`・`sha`・`cha`。入力時は `si`・`ti`・`tu`・`hu`・`zi`・`sya`・`tya` なども受け付けます。

表示用のつづりと入力判定用の候補は `src/data.js` に分けて定義し、促音・拗音などの入力処理は `src/romaji.js` で扱います。

参考資料：文化庁「ローマ字のつづり方」
https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/roma/index2.html

## 学習記録と技術構成

HTML・CSS・JavaScript で動作し、GitHub Pages で公開できる構成です。ゲームサーバー、データベース、API キーは必要ありません。

- **学習記録・設定：** ブラウザーの `localStorage` に保存します。同じブラウザー内で利用するための保存で、別の端末やブラウザーとは自動で同期されません。ブラウザーデータを消去すると記録も消えることがあります。
- **効果音：** Web Audio API で生成します。
- **キャラクター・背景・バッジ画像：** TT-sensei 関連の素材を読み込んで表示します。画像素材を読み込むため、プレイ時にはインターネット接続が必要です。

### 主なファイル

```text
index.html              スタート画面の HTML
styles.css              ゲーム全体のスタイル
beginner/
  index.html            ホームポジション・キー入力の基本練習
src/
  app.js                画面表示・ゲーム進行
  data.js               ローマ字・出題範囲・ことば・キャラクター・バッジ
  sentence-data.js      グランドマスターの文章データ
  monster-data.js       モンスターと出現グループ
  romaji.js              ローマ字の表示・入力判定
  storage.js             学習記録・復習キュー・保存処理
  audio.js               効果音
test/
  romaji.test.js         ローマ字入力の回帰テスト
```

## 開発時の確認

Node.js が使える環境で、リポジトリのルートから実行します。

```bash
npm test
npm run check
```

`npm test` はローマ字入力のテスト、`npm run check` は主要な JavaScript ファイルの構文チェックを実行します。通常のプレイには Node.js のインストールは必要ありません。
